# Android resource adapter

Use this AAR only with a native protected build generated by the Gradle plugin. At the application's
existing localization boundary, construct:

```kotlin
val decoded = LspResourceContext(localizedContext, LspBootstrap::decode, LspBootstrap.namespace)
```

Install it **before** wrappers that transform displayed text (including WeKit's Meow wrapper). Publish
`decoded.resources` through the application's existing `LocalResources`; keep the original Activity
or window context for platform operations. `LspResources(resources, decoder, namespace)` is also public
for applications that already have their own Context wrapper.

The adapter covers `getText`, `getString`, `getQuantityText`, `getQuantityString`, `getTextArray`, and
`getStringArray`, including formatting and default-returning overloads. Android chooses the resource
configuration and plural category; decoding occurs before formatting with the resource configuration's
locale. Host values and another build's tokens pass through. Caller-provided default text (including
null) is returned unchanged. No global context, resource-ID cache, or plaintext cache is maintained.
Recreate the wrapper when configuration changes; `createConfigurationContext` returns a new wrapper.

Resource selection in the plugin is an explicit contract that protected IDs are read through this
adapter. It cannot intercept raw Activity/host Context getters, framework XML consumers, TypedArray,
`getValue`, third-party code, reflection, or APIs receiving resource IDs. Exclude such entries or route
them through the controlled boundary. Pseudolocalization must be disabled. Native bootstrap must finish
before the first protected read. Text that happens to match this build's token namespace is reserved.

The Resources subclass uses Android's deprecated public constructor to match the existing resource
wrapper architecture. It delegates ordinary non-string reads, but is not a universal replacement for
Resources: loader mutation, theme construction, and Activity/window contexts remain outside its role.

Run `:runtime:testDebugUnitTest` for token tests and `:runtime:connectedDebugAndroidTest` for real Android
configuration, plural, formatting, array, host-value and default behavior. The latter installs only the
runtime test package. API 28 and 16 KiB device coverage remain separate validation requirements.
